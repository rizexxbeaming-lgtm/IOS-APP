# Чисто — трекер вредных привычек

Мобильное веб-приложение (PWA), которое помогает бросать вредные привычки —
курение, алкоголь и другие — и наглядно показывает прогресс: дни без срывов,
сэкономленные деньги и вехи здоровья. Вид и ощущения как у нативного iPhone-приложения;
устанавливается на домашний экран и работает офлайн.

> Почему веб, а не Swift: приложение разрабатывалось в Linux-окружении без Xcode,
> поэтому собран mobile-first PWA. Его можно установить на iPhone через Safari
> («Поделиться» → «Добавить на экран „Домой"») или позже обернуть в нативную
> оболочку через [Capacitor](https://capacitorjs.com/) для публикации в App Store.

## Возможности

- **Пресеты привычек**: курение, алкоголь, вейп, сладкое, кофеин, игры или своя.
- **Стрик без срывов**: текущий и лучший, с точностью до минут.
- **Сэкономленные деньги** и количество «несделанного» (невыкуренных сигарет и т.п.),
  считаются вживую исходя из привычного потребления и цены.
- **Вехи здоровья**: таймлайн восстановления организма (для курения и алкоголя —
  по реальным медицинским ориентирам, для остальных — мотивационные вехи).
- **Честный учёт срывов**: отметка срыва обнуляет стрик, но сохраняет историю;
  последний срыв можно отменить.
- **Локальное хранение**: все данные лежат в `localStorage` браузера, без бэкенда
  и без аккаунтов. Светлая и тёмная темы — автоматически.

## Стек

- [Next.js 16](https://nextjs.org/) (App Router) + React 19
- TypeScript
- Tailwind CSS v4
- PWA: web manifest + service worker (офлайн), apple-touch-иконки

## Запуск локально

```bash
npm install
npm run dev
```

Приложение откроется на [http://localhost:43117](http://localhost:43117).

### Прочие команды

```bash
npm run build   # production-сборка
npm run start   # запуск production-сборки
npm run lint    # проверка ESLint
```

## Установка на iPhone

1. Открой приложение в Safari на iPhone.
2. Нажми «Поделиться» → «Добавить на экран „Домой"».
3. Запусти с домашнего экрана — откроется в полноэкранном режиме, как нативное.

## Структура

```
src/
  app/
    page.tsx              # главный экран: список привычек, сводка
    habit/[id]/page.tsx   # экран привычки: кольцо прогресса, вехи, срывы
    layout.tsx            # метаданные, PWA, контейнер под размер телефона
  components/             # карточки, кольцо прогресса, лист добавления, диалоги
  lib/
    types.ts              # модель данных
    presets.ts            # пресеты привычек и вехи здоровья
    habits.ts             # расчёты стриков, денег, вех
    store.ts              # хранилище на localStorage + хуки
    format.ts             # форматирование чисел, дат, русская плюрализация
public/                   # иконки, манифест, service worker
```

## Данные

Данные хранятся только в браузере пользователя (`localStorage`, ключ
`habit-tracker:v1`). Очистка данных сайта удалит все привычки.
